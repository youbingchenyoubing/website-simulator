# 网站模拟器（Website Simulator）需求文档

> 版本：v0.1（初稿）
> 日期：2026-10-09
> 状态：需求沉淀 / 待评审

---

## 1. 项目背景与目标

### 1.1 背景
在培训、产品演示、客服话术演练、运营流程教学等场景中，需要使用"希音卖家中心""亚马逊卖家中心"等电商平台的界面，但：

- 真实账号涉及商业数据隐私，不能用于公开演示；
- 真实平台操作可能产生副作用（误操作、触发风控）；
- 演示环境需要**可控、可重置、可定制**的数据。

### 1.2 目标
提供一个**本地/内网运行的模拟环境**：

1. 用户打开的是"官方网址"（地址栏显示官方域名）；
2. 页面 UI、交互流程与官方卖家中心一致（登录页、数据看板、商品列表等）；
3. 页面中的**所有数据（订单、销售额、商品信息等）由后台管理系统配置**；
4. 支持模拟登录（任意账号密码或后台预设的账号体系）。

### 1.3 非目标（明确不做）
- ❌ 不对外公网提供服务，不面向 C 端真实用户；
- ❌ 不获取、不处理任何真实用户的账号密码；

## 3. 用户与使用场景

### 3.1 角色
| 角色 | 描述 |
|------|------|
| 体验者（学员/观众） | 在模拟浏览器里访问"卖家中心"，体验登录、看数据 |
| 内容管理员 | 通过后台配置每个场景的店铺数据、商品、订单等 |
| 演示者/讲师 | 组织演示流程，切换场景 |

### 3.2 核心场景
1. 讲师启动模拟器 → 选择场景（如"亚马逊新卖家首月"）；
2. 体验者在模拟浏览器地址栏输入 `sellercentral.amazon.com`；
3. 看到与官方一致的登录页 → 用任意/预设账号登录成功；
4. 进入卖家中心首页，看到后台配置的销售额、订单、商品数据；
5. 管理员在后台实时调整数据，体验者刷新页面即变化。

## 4. 功能需求

### 4.1 模拟浏览器（客户端）
| 编号 | 需求 | 优先级 |
|------|------|--------|

| F-102 | 拦截规则可配置：域名 → 模拟站点映射表 | P0 |
| F-103 | 未配置拦截的网址：①直接禁止访问（默认，最安全）或②透传真实网络（可开关） | P1 |
| F-104 | 浏览器界面常规能力：前进/后退/刷新/多标签 | P1 |
| F-105 | 地址栏显示官方域名（视觉一致），但有全局"模拟环境"标识 | P0 |

| 4 | 订单管理页：订单列表、状态流转 | P1 |

### 4.3 后台管理系统
| 编号 | 需求 | 优先级 |

## 5. 非功能需求
- **部署**：单机即可跑（演示笔记本），支持 Docker Compose 一键起；
- **性能**：页面响应 < 300ms（本地环境天然满足）；
- **可扩展**：新增一个平台模板 ≤ 2 人日；
- **安全**：默认只监听 127.0.0.1；管理后台需登录。

## 7. 已确认决策（2026-10-09）
| 问题 | 决策 |
|------|------|
| 拦截方案 | **方案 A**：Electron 壳浏览器 + webRequest 拦截 |
| 平台顺序 | **先 SHEIN 卖家中心，后 Amazon Seller Central** |
| 仿真度 | **1:1 高仿真**（像素级还原布局与交互） |
| 前端路线 | **双轨并行**：①UI 重绘（原方案，兜底）；②**官方前端 + 数据接口拦截**（Electron 中加载真实官方站点，拦截其数据 API 重定向到本地 mock 服务，静态资源不复制、走官方 CDN）。验证可行后优先用②，详见技术文档 §10。 |

### 高仿真度的边界（重要）
- ✅ 布局、配色、组件结构、交互流程按官方页面 1:1 重绘；
- 自己内部使用
