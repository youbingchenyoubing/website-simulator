# 开发交接与任务清单

> 最后更新：2026-10-10
> 用途：供后续开发者或其他模型继续实施，避免依赖对话上下文。

## 1. 项目定位与不可突破的边界

这是仅在本机/经审批内网运行的电商卖家中心**培训模拟器**。业务数据完全来自本地 SQLite；页面必须常驻“模拟环境”标识与水印。

- 不收集、记录或使用真实生产账号密码、Cookie、Authorization。
- 不对官方生产前端的认证、会话、防护或私有 API 做拦截、伪造或绕过。
- 若需复用官方前端，只能接入平台**书面授权**的 sandbox/staging 前端或测试 SDK；详细前置条件见 `docs/04-官方前端复用实施方案.md`。

## 2. 当前架构

```text
apps/site       本地培训演示站点（原生静态 SPA）
apps/admin      本地管理后台（原生静态 SPA）
server          Express + Prisma + SQLite API 与静态资源托管
packages/shared 共享 TypeScript 契约
```

本地数据文件为 `server/data/simulator.db`（已忽略）。Prisma CLI 默认从 `server/.env` 读取 SQLite 地址；部署时可用 `DATABASE_URL` 覆盖。


## 8. 开发注意事项

- 不要将 `server/data/*.db`、`.npm-cache/` 或 `apps/*/dist/` 提交；它们都是生成物。
- 服务器默认只应绑定 `127.0.0.1`。改变 `HOST` 前需要确认内网审批。
- 所有子资源的读写必须按 `scenarioId` 隔离；增加新资源时同步检查路由参数与数据库 where 条件。
- 前端页面禁止硬编码业务数值；UI 文案可以硬编码，业务数据必须来自本地 API。
